## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Up to 16× Upscaling** | Dramatically increase image resolution while preserving sharp details |
| **Multiple Models** | General, photo-realistic, digital art, and anime-optimized models |
| **Batch Mode** | Process hundreds of images in one go with automatic queuing |
| **GPU Accelerated** | Uses your GPU for fast processing of even large image batches |
